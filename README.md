# 🚀 Fabrizio Castro — Portafolio Personal

**Portafolio web moderno, responsive y animado, construido con Angular y TailwindCSS**

---

## ✨ Características

- ⚡ **Angular 17+** con Standalone Components
- 🧩 Nueva sintaxis de control flow (`@if`, `@for`)
- 🌗 **Modo claro / oscuro** con toggle animado
- 🎬 Animaciones de revelación al hacer scroll (Intersection Observer)
- 🃏 Efecto 3D tilt en tarjetas
- ⌨️ Efecto typewriter en la sección principal
- 🔢 Contadores animados
- 📱 **Totalmente responsive** (móvil, tablet y escritorio)

## 🛠️ Instalación local

**Requisitos:** Node.js 18+ y npm

```bash
# 1. Clonar el repositorio
git clone https://github.com/FabrizoCB/Portafolio.git
cd Portafolio

# 2. Instalar dependencias
npm install

# 3. Levantar el servidor de desarrollo
npm start
```

Abrir en el navegador 👉 **http://localhost:4200**

## 📦 Build de producción

```bash
npm run build -- --configuration production
```

Los archivos compilados quedan en `dist/fabrizio-castro-portfolio/`.

## 📁 Estructura del proyecto

## 🤖 Cómo se desarrolló

Diseñé un prompt detallado con los requisitos del sitio (secciones, diseño responsive, animaciones y mis datos) y lo ejecuté en **Windsurf**, un editor con IA, que generó la base del proyecto. Luego lo revisé y lo personalicé.
